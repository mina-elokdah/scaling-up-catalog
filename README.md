# Scaling Up Training Catalog

صفحة عربية ثابتة لورش المهارات والذكاء الاصطناعي والكورسات المجمّعة. افتح `index.html` للمعاينة. بيانات الصفحة موجودة في `catalog-data.js`.

## النشر على GitHub Pages

ارفع **محتويات هذا المجلد** إلى جذر مستودع الموقع. اختار الفرع اللي رفعت عليه ومجلد الجذر من إعدادات GitHub Pages. الصفحة تشتغل من غير تثبيت أو خطوة بناء.

## التسجيل عبر واتساب

زر «سجّل اهتمامك» يفتح واتساب برسالة جاهزة فيها اسم التدريب. فريق Scaling Up يرد ويرسل رابط Google Forms بنفسه. النموذج يجمع تفضيلات التنفيذ والمواعيد والمكان. الدفع على نظملي مرحلة لاحقة.
